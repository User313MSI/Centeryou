# Centeryou

Planning interactif personnel — agenda + tâches + assistant vocal, 100 % en français.

## Lancer l'application

```bash
cd apps/centeryou
npm install
npm run dev    # puis ouvrir http://localhost:3000
```

Production : `npm run build && npm start`.
