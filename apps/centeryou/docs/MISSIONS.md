# MISSIONS.md — Le tableau des missions Centeryou

**Canal partagé entre :**
- **l'Adjudant** (session Vibe Code, bras technique — met à jour ce fichier après chaque étape)
- **Vibe Work** (chef d'orchestre — vérifie, fusionne les PR, déploie, annote ici)

## Règles du canal

1. Chaque mission = une entrée : agent, objectif, état, lien PR, dernière nouvelle (heure UTC).
2. L'Adjudant met à jour ce fichier après chaque étape — c'est le **seul** fichier qu'il commite directement sur `main`.
3. Les agents travaillent chacun sur SA branche et ouvrent leur PR (base `main`). **La fusion des PR reste le rôle exclusif de Vibe Work** (double contrôle : les agents codent, l'Adjudant supervise, Vibe vérifie et fusionne).
4. Quand Vibe Work annote « ✅ fusionnée » : la mission côté code est close. « ❌ refusée (raison) » : l'Adjudant corrige le tir.
5. Conflit entre agents : l'Adjudant arbitre et documente le choix ici.
6. Avant toute nouvelle mission : lire `AGENTS.md`, ce fichier et `apps/centeryou/docs/journal/` — ne jamais refaire ce qui est déjà fait.
7. **Campagne parallèle (« Grand V », 21/11)** : plusieurs agents peuvent coder en même temps, chacun dans SA session Vibe Code dédiée, sur des ZONES ÉTANCHES de fichiers (inscrites dans la mission). Chaque agent publie AVANT de coder un commit sur main (fichier MISSIONS.md uniquement, en pullant d'abord) pour inscrire sa branche, et un autre à la PR. Aucun agent ne touche les fichiers de la zone des autres. Vibe Work fusionne dans l'ordre d'arrivée et arbitre les éventuels conflits. Plafond vague 1 (21/11) : 7 missions en parallèle aux zones étanches (M-07, M-10, M-11, M-12, M-13, M-14, M-15). Vague 2 (M-16, M-17, M-18) : uniquement APRÈS la fusion complète de la vague 1, les zones se recoupant.
8. **Stabilité dans le temps (leçon du 21/11)** : aucun test ne doit dépendre de la date réelle d'exécution. Une date de test qui influence un comportement relatif à « aujourd'hui » doit être recalculée à l'exécution, ou figée par horloge fausse. Une date littérale dans un test ne doit jamais être comparée au jour réel. (Incident : test Cloche périmé à minuit → CI rouge sur main 3 h → blocage temporaire de toute la vague 1, corrigé par Vibe Work, commit d3c67e9.)
