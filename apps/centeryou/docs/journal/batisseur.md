## Journal des étapes

- 2026-11-20 04:54 UTC — Lecture de AGENTS.md, MISSIONS.md et des 15 journaux (héritage Gigi : coquille Electron chargeant l'URL Vercel + repli hors-ligne ; Apollon : polish M-01 fusionné). Branche créée depuis `origin/main` (e423617) et poussée.
- 2026-11-20 04:56 UTC — **Choix d'architecture** : on garde l'architecture de Gigi (l'app Electron charge `https://dev-apps-centeryou.vercel.app`, repli hors-ligne sur `offline.html` + service worker de la PWA). Embarquer le build Next local n'est PAS simple ni sûr ici : la voix premium passe par la route serveur `/api/voix` (ElevenLabs, clé côté Vercel) — un build 100 % local casserait cette route, et changer d'origine (file://) ferait perdre le localStorage existant des utilisateurs. La version en ligne redéployée depuis main est donc embarquée « par URL », ce qui garantit que le .exe contient toujours la version parfaite polie par Apollon.
- 2026-11-20 04:57 UTC — **Configuration electron-builder** (`apps/centeryou-desktop/package.json`) : appId `com.centeryou.app`, `productName` « Centeryou », `author`/`publisherName` « Origine », `copyright` « © 2026 Origine », description en français, version 1.0.0. Cible unique : **NSIS x64 Windows** (`dist:win` = `electron-builder --win --x64`) → `dist/Centeryou-Setup-1.0.0.exe`. NSIS : `oneClick: false` (assistant guidé), `perMachine: false` (installation dans les données locales utilisateur, sans droits admin), `allowToChangeInstallationDirectory: true`, `installerLanguages: ["fr"]` + `displayLanguageSelector: false` + `unicode: true` (assistant 100 % français), `createStartMenuShortcut: "always"` (menu Démarrer obligatoire), `createDesktopShortcut: true` (bureau proposé), `shortcutName: "Centeryou"`, `menuCategory: true`, `runAfterFinish: true` (case « Lancer Centeryou »), `deleteAppDataOnUninstall: false` (**données utilisateur conservées** à la désinstallation), icônes installeur/désinstalleur `build/icon.ico`. Cibles mac/linux retirées (mission Windows uniquement ; `dist` = `dist:win`). `.gitignore` (racine + desktop) : ajout de `*.exe`, `out/`, `release/` — **aucun binaire ne peut entrer dans le dépôt** (`dist/` déjà ignoré).
- 2026-11-20 04:58 UTC — `main.js` : lien de mise à jour par défaut corrigé vers `https://github.com/User313MSI/Centeryou/releases` (le dépôt s'appelle Centeryou, comme corrigé par Apollon côté web). Vérification voix/réglages : `main.js`/`preload.js` ne bloquent rien — micro autorisé uniquement pour l'origine de production via `setPermissionRequestHandler` (jamais la caméra), `localStorage` du renderer intact (réglages Zustand persistés dans `%APPDATA%\Centeryou`), Web Speech API (synthèse + reconnaissance) disponible dans Chromium, voix premium via `/api/voix` côté Vercel avec repli Web Speech hors-ligne (voir `src/lib/voice.ts`).
