Embarquer le build Next local n'est PAS simple ni sûr ici : la voix premium passe par la route serveur `/api/voix` (ElevenLabs, clé côté Vercel) — un build 100 % local casserait cette route, et changer d'origine (file://) ferait perdre le localStorage existant des utilisateurs. La version en ligne redéployée depuis main est donc embarquée « par URL », ce qui garantit que le .exe contient toujours la version parfaite polie par Apollon.
