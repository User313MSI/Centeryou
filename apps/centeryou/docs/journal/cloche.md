## Décisions importantes

- **Heures locales murales partout** : `reminderDateTime` = `parseISO(occurrence)` + `setMinutes(start − lead)` sur des `Date` locales — aucun UTC, aucun décalage DST (même modèle que `addDaysISO`).
- **Rappel « dû » = instant atteint ET événement pas encore commencé** : à la réouverture, un rappel manqué (app fermée) est rattrapé UNE fois si l'événement n'a pas commencé — jamais de notification pour un événement passé, et un événement supprimé n'est plus dans la liste donc plus jamais rappelé (test « fantôme »).
- **Tampon persisté séparé** (`centeryou-rappels-v1`, hors du store zustand) : `notifies` (par occurrence/génération), `fait` (Terminé), `snoozes` (report), `tachesDate` (tâches) — sanitize à la lecture, pruning à 3 jours, borné à 500 entrées.
- **Permission jamais au chargement** : uniquement au geste (submit d'un événement avec rappel, ou bouton Réglages). Refusée → explication FR dans Réglages + toast à la création.
- **Boutons natifs seulement si le navigateur le permet** (`maxActions ≥ 2` + SW) ; sinon toast « Reporter » dans l'app. Clic simple → page Aujourd'hui + halo de mise en vedette (statique si reduced-motion).
- **Champ `reminderMinutes` optionnel** : zéro migration cassée, `sanitizeEvents` répare sans toucher aux `toEqual` existants ; sauvegarde JSON et synchro passent par le même sanitize (des deux côtés).
- **Zéro voix** dans les rappels (aucun `speak`), voix/mode sombre jamais gated Premium, tokens inchangés, aucune variable d'env renommée, pas de sidebar, interface 100 % FR, mobile 360 px (mêmes patterns flex/grid que les cartes existantes).
